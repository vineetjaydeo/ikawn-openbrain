What separates amateur from professional dark UI

Same palette, same components — the difference is in layering, depth, and restraint

1. Layered Elevation (not flat cards)
Pro UIs use 3-4 background layers that create depth. Each layer is slightly lighter. Borders are subtle, not structural.

2. Text Hierarchy (not everything the same weight)
Pro UIs have 4-5 distinct text levels. Muted text is actually muted. Primary text isn't pure white — it's #e4e4e7 or #fafafa.

Pro UIs use a 4px/8px grid. Consistent spacing creates rhythm. Generous whitespace signals confidence.

4. Micro-details (the 1% that makes 90% of the difference)
Inner shadows on buttons, subtle gradients on backgrounds, rgba borders instead of hex, transition on everything interactive.
