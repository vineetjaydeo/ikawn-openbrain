Key Design Decisions

Single Process

Everything runs in the same Express process. No separate worker process, no Redis, no message broker. Fly.io's single machine handles it. Scale later if needed.

Postgres is the Queue

No Bull, no BeeQueue, no Redis. scheduled_tasks + next_run_at + polling = good enough for dozens of tasks. Advisory locks prevent double-execution.

Tools are Files

Drop a .tool.js file → it's available to both scheduler and Claude. Standard interface means browser extension is just another tool file.

Approval is Async

Tier 2 tasks that need approval don't block the scheduler. They pause, notify via Telegram, and resume when the user responds. Callback via Telegram inline buttons.
