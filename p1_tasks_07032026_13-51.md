Four Priority 1 tasks. Do tasks 1 and 2 first, completely, before touching 3 and 4.
Task 1 — Unify Ruhi's brain across channels
/api/ruhi/chat.post.ts on ikawn OS currently uses Gemini Flash with its own self-contained memory. This breaks the one-brain architecture. Fix:

Before every Gemini response, call OpenBrain GET /search?q={userMessage}&brand_id=ikawn&limit=5 for RAG context. Inject results into the system prompt.
After every response, call captureMessage() via OpenBrain POST /capture — both the user message (inbound) and Ruhi's response (outbound), with source: 'ruhi-layer1', brand_id: 'ikawn'.

Ruhi must speak from one memory regardless of channel — Telegram, web chat, or os.ikawn.com.
Task 2 — Wire the completion webhook
The /api/actions/complete endpoint exists on OpenBrain but is never called. Generation results are invisible to OpenBrain's memory.
Fix in packages/app/server/api/external/generate.post.ts:

When an external API caller triggers a generation, pass webhookUrl: 'https://ikawn-openbrain.fly.dev/api/actions/complete' into the Fal job or fal-poller completion handler.
On completion, OpenBrain receives the result URLs, stores them in the generations table, and runs captureMessage() so generations are searchable in memory.


Task 3 — Fix generation batch count awareness
OpenClaw doesn't know Genie and Remix return 4 images per generation call. It's triggering 4x more generations than needed.
Fix:

Add batch_size (default 4) and output_count columns to OpenBrain's generations table.
When /api/actions/complete receives results, store all URLs and set output_count.
Update the OpenBrain actions proxy response to return the full array of result URLs back to the caller, not just a generation ID.
Update OpenClaw's SKILL.md: when user asks for N images, divide by batch_size (4) to determine how many trigger calls to make. Default ask = 1 call = 4 images.

Task 4 — Gallery browsing and image reuse via API
Add a gallery browsing capability so OpenClaw can find past generations and use them as input for new ones.
On ikawn OS — add GET /api/external/generations (paginated, no ID): returns past generations for the authenticated API key, filterable by agent and date. Each result includes the full output_urls array, prompt, agent_name, created_at.
On OpenBrain — add GET /api/gallery proxy endpoint that calls the above and returns results to OpenClaw.
Update OpenClaw SKILL.md with gallery commands:

Browse gallery: fetch recent generations, display URLs + prompts
Find by description: semantic search on prompt text via OpenBrain /search
Reuse image: pass a selected URL as reference_image parameter into a new generation call

Before implementing reference_image support, check what's already wired in generate.post.ts — Fal.ai image-to-image and first-frame-to-video may already be partially supported. Don't rebuild what exists. Flag what's missing and what's ready.
