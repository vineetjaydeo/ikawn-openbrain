### 3. Tool Execution Harness (reasoning-loop.js)
Five layers of protection:
1. **Text-based tool call recovery** — Two formats: `toolName({...})` and XML `<invoke name="...">`
2. **tool_choice compliance validation** — If forced tool not called, injects system reminder and retries
3. **Input schema validation** — Checks required fields before execution
4. **Mandatory tool_result pairing** — Orphaned tool_use blocks get synthetic error results
5. **Registry validation** — Verifies forced tool exists before sending to API

### 5. Task Persistence on Refresh
