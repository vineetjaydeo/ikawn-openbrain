### 1. Real-Time Memory (Parts A/B/C)
- **Part A — Recency injection** (`src/routes/chat-api.js`): `getRecentActivity()` fetches 10 most recent memories by timestamp, injected into system prompt as `=== RECENT ACTIVITY ===` before RAG results. Runs in `Promise.all` with `searchMemories()` — zero added latency.
- **Part B — Activity digest worker** (`src/engine/background-executor.js`): `runActivityDigest()` runs every 4 hours via `setInterval`. Queries memories since last digest, summarizes with Haiku, saves as `memory_type: 'activity_digest'`. New `whats_new` v1 tool (`src/tools/whats_new.tool.js`) for pure time-based queries.
- **Part C — Deploy capture** (`src/index.js`): `captureMessage()` on startup records version, timestamp, Node version, PID as `memory_type: 'system_event'`.
